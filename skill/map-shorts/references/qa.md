# QA before you show or publish

Render stills at the hook, every camera key, each card, and the last second.

- [ ] Hook claim visible as a title in the first 2 s and spoken at once
- [ ] Something new on screen at least every 4 s; no long static stretch
- [ ] Subject centred and not under a card (top ~210 px / bottom ~310 px are covered by the platform)
- [ ] Every card readable for 2 s+; counters finish before the next beat
- [ ] Captions match the speech; written form for numbers/names
- [ ] Overlays visible (a `country` fill on mountains needs a higher `lift`); no flat bars where a column should read
- [ ] Credits line present and complete
- [ ] Every number checked against two sources; "about" where approximate
- [ ] User listened to the voice
- [ ] No API key, signed URL or personal path in any file you will commit
